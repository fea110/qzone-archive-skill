# 常见问题

## 安装后没有出现在当前会话？

检查 `skills/qzone-archive/SKILL.md` 路径和 profile 是否正确，再开启新会话。已运行会话可能缓存技能目录。不要靠改模型配置解决路径问题。

## 可以直接双击运行吗？

不可以。它是 Hermes 流程型技能，安装脚本只复制技能文件，实际归档通过 Hermes 模型和浏览器工具执行。

## 二维码过期了？

让 Hermes 刷新 QQ 登录页，再使用最新截图扫码；不要重复扫旧二维码。不要在聊天发验证码。

## 为什么数量少了？

可能是分页未加载、重复页、隐藏条目、截断正文或回复未展开。查看 ID 去重、原页可见数量与核验清单。无法访问的内容不能补造。

## 图片文件存在却不能预览？

可能下载到 HTML 错误页或“图片暂停访问”占位图。必须实际解码并视觉检查，再核对 Markdown 引用路径。失效源应记录并跳过。

## 原页面时间不完整怎么办？

保留原字符串，例如仅月日或仅日期；不要从帖子 ID 推断完整时间，也不擅自补年份和秒数。

## 评论为什么像一大段聊天？

整页文本拼接会混入作者标签和楼内回复。应从 DOM 主评论节点和回复节点分别提取，再按真实父子关系生成 Callout。说说、留言板需要各自验证，不套用日志解析结论。

## Obsidian 弹出 Vault not found？

检查实际注册的 Vault 与相对笔记路径。深链接空格应编码为 `%20`，不要用 `+`。系统打开命令返回成功仅表示请求已发出，还需查看应用实际结果。

## 这是完整的 QQ 空间备份吗？

不是。默认范围是可访问的日志、说说、留言板及可下载图片；视频、音频、相册、私密日记、草稿和回收站不属于默认范围。可见回复也未必是全部回复。

## Windows / Linux 可以用吗？

手动安装目录结构相同，脚本使用跨平台标准库；但 QQ 归档全过程只在 macOS 真实案例验证过。不同环境必须重新确认浏览器工具、登录和文件权限。
